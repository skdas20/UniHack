Step 3: Brand & Manufacturer Entity Resolution
When raw catalog rows list distributor cooperatives (e.g. Appliance Dealers Cooperative (APPDE)) or messy spellings (e.g. Black & Decker/dewlt (2585)):

Extract potential brand tokens from Part_Desc and Mfg_Part_Num prefixes (e.g., Milw, Dewalt, Diablo, Frigidaire, Satco).
Run fuzzy matching against the 27,000+ row master brand/mfg list.
Replace raw distributor names with canonical legal entities containing ® / ™ (e.g., DEWALT®, FRIGIDAIRE®, Milwaukee®).
Step 4: Taxonomy Classification & Attribute Extraction
Classpath Classification:
Predict category node (e.g., Tools > Power Tools > Saws > Circular Saws).
Can be achieved using embeddings (e.g., text-embedding-004 or Sentence-Transformers) + cosine similarity against the canonical Classpath list.
Attribute Extraction with Strict LOV Constraints:
Extract measurements, voltages, materials, colors, mounting styles, and pack quantities.
Rule: Do not invent values. Every attribute value must be mapped to the closest canonical value in the LOV.
UOM & Fraction Formatting:
Ensure standard spacing: 24 in (never 24in).
Convert compound inch measurements: 50.25" 
→
→ 50-1/4 in.
